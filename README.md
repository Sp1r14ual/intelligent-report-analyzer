# Система интеллектуального анализа университетской отчётности и автоматической генерации дашбордов

Программный комплекс для автоматизированного анализа статистической и управленческой отчётности образовательных организаций на основе архитектуры **Retrieval-Augmented Generation (RAG)** и системы автоматической генерации аналитических витрин в **Apache Superset**.

Система позволяет загружать PDF-документы отчётов (ВПО-1, НИОКР и др.), автоматически извлекать их структуру и таблицы, выполнять семантический поиск, получать ответы на вопросы на естественном языке, а также по текстовому запросу создавать интерактивные дашборды с графиками — **полностью локально, без передачи конфиденциальных данных во внешние облачные сервисы**.

---

## 🚀 Ключевые возможности

| Функция | Описание |
|---|---|
| 📄 **Интеллектуальный парсинг** | Извлечение структуры, текста и таблиц из PDF любого объёма через **Docling** |
| 🔍 **Гибридный RAG-поиск** | Векторный поиск по текстовым чанкам и таблицам через **BGE-M3** и **FAISS** |
| 🎯 **Нейросетевое переранжирование** | Уточнение релевантности контекста с помощью **CrossEncoder (BGE-Reranker)** |
| 📊 **Генерация дашбордов Superset** | Создание дашбордов и чартов в Apache Superset по текстовому запросу пользователя |
| 🛡️ **SQL Guard & Semantic Layer** | Автоматическая валидация SQL: запрет DDL/DML, маскирование PII, whitelist таблиц |
| 🏠 **100% On-Premise безопасность** | Локальный инференс модели **YandexGPT 5 Lite 8B** через высокопроизводительный `llama-server` |

## 🛠 Стек технологий

* **Обработка документов:** Docling, PyMuPDF, Python-Markdown.
* **Векторный поиск и Retrieval:** FAISS-CPU, `BAAI/bge-m3` (эмбеддинги), `BAAI/bge-reranker-large` (CrossEncoder).
* **Языковая модель:** YandexGPT 5 Lite 8B (инструктированная квантованная версия `Q4_K_M` в формате GGUF).
* **Среда инференса:** `llama-server` (`ghcr.io/ggml-org/llama.cpp:server`).
* **Пользовательский интерфейс:** Streamlit.
* **Аналитическая платформа (BI):** Apache Superset 3.1.3.
* **База данных и кэш:** PostgreSQL 16 (схема документов и витрины `analytics.*`), Redis 7.
* **Контейнеризация:** Docker, Docker Compose.

## ⚡ Быстрый старт через Docker (Рекомендуемый способ)

Все компоненты комплекса (веб-интерфейс, языковая модель, PostgreSQL, Redis и Apache Superset) разворачиваются одной командой с помощью **Docker Compose**.

### 1. Требования

* Установленный **Docker** и **Docker Compose** (Docker Desktop для Windows/macOS или Docker Engine для Linux).
* Минимум 8–10 ГБ свободной оперативной памяти (для одновременной работы модели 8B и Superset).

### 2. Подготовка модели и окружения

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd masters-diploma-project
   ```

2. Поместите файл весов модели в директорию `models/`:
   ```
   models/
   └── YandexGPT-5-Lite-8B-instruct-Q4_K_M.gguf
   ```

3. Создайте файл конфигурации `.env` на основе примера:
   ```bash
   cp .env.example .env
   ```

### 3. Запуск всего комплекса

Выполните команду в корне проекта:

```bash
docker compose up -d --build
```

Docker поднимет и согласует следующие сервисы:
* **`postgres_container`** (порт `5432`) — база данных с предзагруженными аналитическими витринами.
* **`redis_container`** (порт `6379`) — кэширование и очереди.
* **`superset_init_container`** — автоматически накатывает миграции, создаёт администратора `admin:admin` и инициализирует роли Superset.
* **`superset_container`** (порт `8088`) — веб-интерфейс аналитической платформы.
* **`llama_container`** (порт `8080`) — сервер инференса модели YandexGPT.
* **`app_container`** (порт `8501`) — основное приложение Streamlit.

### 4. Доступ к интерфейсам

* **Основное веб-приложение:** [http://localhost:8501](http://localhost:8501)
* **Аналитическая платформа Superset:** [http://localhost:8088](http://localhost:8088)
  * *Логин:* `admin`
  * *Пароль:* `admin`

### 5. Полезные команды

* **Просмотр логов приложения:**
  ```bash
  docker compose logs -f app
  ```
* **Просмотр логов сервера языковой модели:**
  ```bash
  docker compose logs -f llama
  ```
* **Остановка всех сервисов:**
  ```bash
  docker compose down
  ```
* **Остановка с удалением данных (полная очистка):**
  ```bash
  docker compose down -v
  ```

## 💻 Локальный запуск (без Docker)

Если вы хотите запускать приложение для разработки напрямую на хост-машине:

### 1. Виртуальное окружение Python

Рекомендуется использовать **Python 3.11**:

```bash
python -m venv .venv

# Windows (PowerShell / CMD)
.venv\Scripts\activate

# Linux / WSL
source .venv/bin/activate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Запуск PostgreSQL и Superset

Проще всего запустить инфраструктурные сервисы через Docker Compose:
```bash
docker compose up -d postgres redis superset
```

### 4. Запуск сервера языковой модели

* **В Windows:**
  Запустите скрипт:
  ```cmd
  run_llama_server.bat
  ```

* **В Linux / WSL:**
  ```bash
  chmod +x run_llama_server.sh
  ./run_llama_server.sh
  ```
  *(Сервер запустится на адресе `http://127.0.0.1:8080`)*

### 5. Запуск веб-интерфейса Streamlit

```bash
streamlit run app.py
```

Откройте в браузере: [http://localhost:8501](http://localhost:8501)

## ⚙️ Настройки и переменные окружения (.env)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LLM_BASE_URL` | `http://llama:8080` | URL REST API сервера языковой модели |
| `LLM_GPU_LAYERS` | `18` | Количество слоёв нейросети, выгружаемых на GPU |
| `LLM_CTX` | `8192` | Размер контекстного окна модели (токенов) |
| `SUPERSET_URL` | `http://superset:8088` | Внутренний URL Superset для вызовов API из контейнера |
| `SUPERSET_PUBLIC_URL` | `http://localhost:8088` | Внешний URL Superset, открываемый в браузере пользователя |
| `SUPERSET_USERNAME` | `admin` | Логин администратора Superset |
| `SUPERSET_PASSWORD` | `admin` | Пароль администратора Superset |
| `POSTGRES_HOST` | `postgres` | Хост базы данных PostgreSQL |
| `POSTGRES_PORT` | `5432` | Порт PostgreSQL |
| `POSTGRES_DB` | `analytics_db` | Имя аналитической базы данных |
| `POSTGRES_USER` | `superset` | Пользователь PostgreSQL |
| `POSTGRES_PASSWORD` | `superset` | Пароль пользователя PostgreSQL |

## 📊 Примеры работы

### 1. Чат с отчётами (RAG)
* *«Сколько всего студентов обучалось в 2025 году на очной форме?»*
* *«Найди раздел с финансированием научных исследований и покажи объёмы грантов РНФ»*
* *«Посчитай суммарные затраты на приобретение оборудования по всем факультетам»*
* *«Проверь, нет ли расхождений между таблицей 2.1 и итоговыми показателями раздела 4»*

### 2. Генерация дашбордов Superset
* *«Построй аналитический дашборд по контингенту студентов факультетов»*
* *«Создай мониторинг финансирования НИОКР и грантовой поддержки»*
* *«Сформируй дашборд результативности научной деятельности лабораторий»*

Сгенерированный дашборд импортируется напрямую в Apache Superset через API и становится доступен по прямой кликабельной ссылке в интерфейсе, а также доступен для скачивания в виде ZIP-архива с ассетами.
